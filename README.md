# Web Performance Optimization Project

## 📌 About the Project

This project focuses on improving the performance and loading speed of a simple web application using HTML, CSS, and JavaScript.

The main objective is to reduce image size, improve loading performance, and use browser-side caching to avoid unnecessary API requests.

## 🎯 Objectives

* Improve website loading speed.
* Optimize images to reduce file size.
* Implement browser-side caching using localStorage.
* Measure website performance using Google Lighthouse.
* Deploy the website using GitHub Pages.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Lighthouse
* Squoosh Image Optimizer
* Git and GitHub
* GitHub Pages

## ⚡ Optimizations Implemented

### 1. Performance Analysis

Used Google Lighthouse to analyze website performance and identify areas for improvement.

### 2. Image Optimization

Optimized the website image by converting it to WebP format and reducing its file size.

Image optimization helps reduce download time and improve page loading speed.

### 3. Image Display Optimization

Used appropriate image dimensions and loading priority settings to improve image rendering.

Implemented browser-side caching using JavaScript and localStorage.
